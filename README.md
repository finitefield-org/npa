# npa

NPA (Nano Proof Auditor) is a certificate-first proof assistant and
verification toolchain for dependent proofs. The project separates the small
trusted proof-checking base from untrusted authoring tools, theorem packages,
agent workflows, and browser-facing proof interfaces.

NPA is developed by [Finite Field K.K.](https://finitefield.org/en/).

## Public Repositories

- [npa](https://github.com/finitefield-org/npa): public umbrella repository
  for the NPA project family
- [npa-core](https://github.com/finitefield-org/npa-core): kernel,
  certificate format, checker, frontend, tactic layer, and package CLI
- [npa-std](https://github.com/finitefield-org/npa-std): small public
  standard-library package
- [npa-mathlib](https://github.com/finitefield-org/npa-mathlib): public
  theorem-library package
- [npa-web](https://github.com/finitefield-org/npa-web): local browser tool
  for the human-facing NPA proof flow
- [npa-project-fermat-last-theorem](https://github.com/finitefield-org/npa-project-fermat-last-theorem):
  public standalone Fermat Last Theorem proof project package
